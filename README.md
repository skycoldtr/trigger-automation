# TRIGGER // Automation Engine

TRIGGER is a Python-based desktop automation tool that uses image recognition to trigger automated clicks and keyboard actions.

## Features
- 🎨 **Dark / Light Theme Support**
- 🌐 **Multi-language Support (EN / TR)**
- 🎯 **Image-based Automation (PyAutoGUI)**
- ⚙️ **Configurable Delay & Confidence Values**
- 💾 **Profile Save & Load (JSON)**
- 🛑 **Emergency Abort Hotkey (Q)**

## Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/skycoldtr/trigger-automation.git](https://github.com/skycoldtr/trigger-automation.git)
